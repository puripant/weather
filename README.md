# weather
A simple web app for testing weather forecast interfaces. The first prototype was generated by Claude Code (Opus 5.5 with medium effort) in October 2026 with the following prompts:

- I want a minimal web app that shows temperature and chance of rain on a clock interface (so the forecast is at most 12 hours from the current time). Find a free and reliable weather API that is accurate in Thailand. References include apps called Partly Cloudy and Climate Clock.
- Can you add two more views of temperature and chance of rain for 7 days and 4 weeks in a calendar form?
- The 7-day view should be vertical as this web should be responsive and fit the vertical screen of a mobile phone. The 4-week view should always start from Monday. Since an accurate forecast runs for 16 days, there's no need to fill 28 days; just for 4 rows of dates are enough. A thin line separate weekdays from weekends should be good too.
- No need to write the date or the fourth row of the 4-week at all. Name the views as clock, week, month. Align the dates in 7-day (week) view.
